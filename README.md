# 🤖 Devion

**Devion** é um bot multifuncional para servidores Discord, desenvolvido para oferecer ferramentas de **moderação, comunidade, atendimento e administração**.

> **Devion • Sempre ao seu lado.**

## ✨ Recursos

* 🛡️ **Moderação** — ferramentas para manter o servidor organizado e seguro
* 🎫 **Atendimento** — sistema de tickets para suporte
* 👤 **Informações de membros** — consulta de usuários e perfis
* 📊 **Informações do servidor** — dados e estatísticas
* 🗳️ **Enquetes** — criação de votações
* 🔒 **Controle de canais** — bloqueio, desbloqueio e slowmode
* ⚙️ **Administração** — comandos para gerenciamento do servidor
* 📝 **Logs** — registro de ações importantes

## 🎯 Objetivo

O Devion foi criado para reunir ferramentas essenciais em um único bot, facilitando a **administração e organização de servidores Discord**.

## 🛠️ Tecnologias

* **Python**
* **discord.py**
* **Discord API**

## 📋 Comandos

O Devion possui comandos de:

* Moderação
* Administração
* Atendimento
* Informações
* Enquetes
* Gerenciamento de canais

Use `/help` dentro do servidor para visualizar os comandos disponíveis.

## 🔐 Segurança

O Devion utiliza variáveis de ambiente para armazenar informações sensíveis.

**Nunca coloque o token do bot diretamente no código ou publique tokens no GitHub.**

## 🛡️ Devion Guard

O **Devion Guard** é o projeto de segurança da família Devion, desenvolvido separadamente para proteção de servidores contra ameaças como spam, raids e ações destrutivas.
