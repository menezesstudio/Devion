# 🤖 Devion

**Devion** é um bot para servidores Discord, desenvolvido para oferecer ferramentas de moderação, comunidade e atendimento.

## ✨ Recursos

- 🛡️ Moderação
- 🎫 Sistema de atendimento
- 📊 Informações do servidor
- 👤 Informações de membros
- 🗳️ Enquetes
- 🔒 Controle de canais
- ⚙️ Comandos administrativos

## 🛠️ Tecnologias

- Python
- discord.py
