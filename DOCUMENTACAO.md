# 🤖 Devion — Documentação

> **Devion • Sempre ao seu lado.**

## 📖 Sobre

O **Devion** é um bot multifuncional para servidores Discord, desenvolvido para oferecer ferramentas de moderação, comunidade, atendimento e administração.

## ✨ Recursos

- 🛡️ Moderação
- 🎫 Sistema de tickets
- 👤 Informações de membros
- 📊 Informações do servidor
- 🗳️ Enquetes
- 🔒 Controle de canais
- 📝 Sistema de logs
- ⚙️ Ferramentas administrativas

## 📋 Comandos

Use `/help` dentro do servidor para visualizar os comandos disponíveis.

### 🛡️ Moderação

- `/kick` — Expulsa um membro.
- `/ban` — Bane um membro.
- `/unban` — Remove o banimento de um usuário.
- `/mute` — Silencia um membro.
- `/unmute` — Remove o silêncio.
- `/warn` — Adverte um membro.
- `/warnings` — Mostra as advertências.
- `/clearwarns` — Remove as advertências.

### 🔒 Canais

- `/clear` — Apaga mensagens.
- `/lock` — Bloqueia um canal.
- `/unlock` — Desbloqueia um canal.
- `/slowmode` — Configura o modo lento.

### 📊 Informações

- `/userinfo` — Mostra informações de um membro.
- `/serverinfo` — Mostra informações do servidor.
- `/avatar` — Mostra o avatar de um usuário.
- `/botinfo` — Mostra informações do Devion.
- `/ping` — Mostra a latência do bot.

### 🗳️ Comunidade

- `/poll` — Cria uma enquete.
- `/say` — Faz o Devion enviar uma mensagem.

## 🎫 Atendimento

O Devion possui um sistema de tickets para facilitar o atendimento e o suporte aos membros.

## 📝 Logs

O Devion possui um sistema de logs para registrar ações importantes realizadas no servidor.

## 🔐 Segurança

Informações sensíveis, como o token do bot, devem ser armazenadas em variáveis de ambiente.

**Nunca publique o token do Devion no GitHub.**

## 🛠️ Tecnologias

- Python
- discord.py
- Discord API

## 🚀 Desenvolvimento

O Devion está em desenvolvimento contínuo. Novos sistemas, melhorias e comandos serão adicionados futuramente.
